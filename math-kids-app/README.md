MathFun for Kids
=================

A simple, local web app to practice basic arithmetic for young learners.

Files
- index.html — main UI
- styles.css — small stylesheet for a colorful, kid-friendly look
- script.js — problem generator, scoring, sounds, simple animations

How to run
1. Open `C:/Users/mbg/draft/math-kids-app/index.html` in any modern browser (Chrome, Edge, Firefox).
2. Choose an operation (Mixed, Addition, Subtraction, Multiplication, Division) and a difficulty.
3. Press Start and answer the problems. Correct answers give points and a short star animation.
